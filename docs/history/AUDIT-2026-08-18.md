# Audit — 2026-08-18

What the config files and the SPEC promised, and what the code actually did.
Kept because the *method* is repeatable and the findings explain why several
things are shaped the way they are.

> Reconstructed from the session record after the old `TODO.md` was replaced by
> the clean one. The findings and reasoning are intact; the original wording of
> the pre-audit sections is not.

## The two sweeps that found everything

Both are mechanical, and both found things no amount of reading would have.

1. **For every `pub` field in `config/schema.rs`, grep for a real `.field`
   ACCESS outside `config/`.** Grepping the bare *name* gives false negatives —
   the word turns up in unrelated comments, which is how `[keys].prefixes`
   nearly slipped past.
2. **Delete the crate-wide `#![allow(dead_code)]` and read what falls out.**
   `main.rs` had said to remove it "once steps 7–11 are implemented". They had
   been, long since. It was hiding 24 items.

## Settings that were pure fiction

In the schema, documented in `shoin/*.conf`, read by nothing.

- **`input.escape_alias`** (`jk` to leave Insert) — also in SPEC §7.2, and *zero
  code*. Built as `App::feed_escape_alias`. The first character must land
  immediately or typing "jam" stutters, so it runs *after* the insert and takes
  its own characters back.
- **`input.sequence_timeout_ms`** — its only consumer was `Pending::expire`,
  which nothing called. It now bounds one thing: the gap between the alias's
  characters. `Keymap::lookup` answers `Found` before `Prefix`, so an exact
  match fires at once and there is no ambiguity to resolve on a timer.
  `expire` and `Pending::since` were deleted; SPEC §7.2 said otherwise and was
  wrong.
- **`editor.auto_pair`** — built, with the rules its own "prose is full of
  unmatched quotes" comment implies: a quote never pairs against a word
  character, and nothing pairs in front of one.
- **`layout.hanging_indent`** — SPEC §6 promised it and `VisualRow::hanging` sat
  unread. Built. The non-obvious third step: `frame::hang_x` subtracts
  `gutter_shift`, because `VisualRow::hanging` is measured from the *line's*
  left edge and a revealed line's edge sits `gutter_shift` columns left of the
  text column. Without it a revealed task's continuation lands four columns
  right of its own first row.
- **`editor.auto_indent`** — implemented as "copy the leading whitespace" but
  *described* as "continue list markers / quote prefixes". The description was
  the better feature, so the code moved to match.
- **`layout.line_spacing`** — REMOVED rather than built; see `TODO.md` #2 for
  the cost.
- **`[keys].prefixes`** — a declaration list for a validation rule that never
  existed. `g`, `z` and `<C-w>` are built-in prefixes in `bindings.rs`. Removed.

## Things wired to nothing

- **The external-modification guard.** `Buffer::disk_mtime` was recorded on open
  and save, `fs::save::changed_externally` was written and documented as "we
  must prompt rather than clobber" — and **never called**. Shoin silently
  overwrote files another program had changed. Now refused, with `:w!` / `:wq!`
  as the way past, and only when the target *is* the file that mtime describes.
- **`r{c}` did nothing.** `Pending` emitted `Action::ReplaceChar`, `App` had a
  `replace_chars` method, and no arm connected them — `apply_action`'s `_ => {}`
  swallowed it. It is listed in `:help bindings`.
- **`[keys.insert]` was built from config and never consulted.** Its one shipped
  binding (`<C-s>`) worked only because Insert mode hardcodes Ctrl-s.
- **An unbound `<C-a>` typed an `a`** — a control chord arrives as its plain
  letter plus CONTROL, and the plain-character arm caught it.
- **`keymap.rs`'s two documented validation rules** ("a loud startup error on
  violation") were never implemented. Rule 2 (duplicate sequences) is impossible
  — TOML rejects duplicate keys. Rule 1 is real and is now a warning.
- **Quitting checked only the visible buffer on the binding path.** `:q` counted
  every document; `Action::Quit`/`WriteQuit` — what `<leader>q` reaches — looked
  at `self.buffer.modified` alone, so quitting from a binding discarded a
  modified background buffer without a word. Both go through `App::try_quit`.
- **`<C-w>` + an arrow did nothing.** `bindings::after_prefix` opened with
  `let KeyCode::Char(c) = key.code else { return None }`, dropping every
  non-character second key. The file tree runs its *own* `<C-w>` prefix and had
  the same bug — there are two places.

## Dead code the blanket allow was hiding

Notably **a whole duplicate copy of the input grammar in `app.rs`** (`Awaiting`
+ `motion_for`), left behind by the 2026-08-17 relocation into `input/`.
Rebinding a motion would have meant editing the wrong table.

Also: six unreachable `Action` variants, `Selection`/`SelectionKind`,
`Motion::SearchNext`, `style_line`, `overlay_fg`, `delete_range`,
`keymap_table`, `format_seq`/`format_key`, `screen_motion`, `focus_direction`,
`reset_render_cache`, and two per-line allocations nothing read
(`LineEntry::concealed`, a `String` per line of the document, and
`ConcealMap::display_width`, a width pass per line per parse).

## Structural fixes — do not undo these

- **`App::apply_action` is EXHAUSTIVE.** The `_ => {}` catch-all is replaced by
  an explicit enumeration of the variants `run` handles. That catch-all is
  exactly how `r{c}` compiled and did nothing; a new `Action` must now be
  handled or it will not build.
- **No crate-wide `allow(dead_code)`.** The one field that legitimately leads
  its use (`VisualRow::editable`, the SPEC §14.5 seam) carries a targeted one.
- **`newline_with_indent` calls `refresh_blocks()` first** — the block cache is
  refreshed by the RENDER path, so between two keys in one event batch it can
  still describe the line before the last edit.
- **`theme.rs::the_shipped_theme_matches_the_built_in_default`** asserts
  `shoin/theme.conf` parses to exactly `Theme::default()`. They had already
  drifted (`selection` and `tag_bg`). It checks per-key first so a failure names
  the role, then wholesale to catch an omitted one.

## Licensing (same day)

Relicensed **Apache-2.0**. `Cargo.toml` previously declared `license = "MIT"`
with no LICENSE file in the tree at all.

- `LICENSE` is the canonical text, appendix and bracket placeholders intact —
  75 independently vendored copies in the local crate registry are
  byte-identical to it, and its legal body cross-checks against the Rust
  toolchain's own `Apache-2.0.txt`.
- **Dependency audit before relicensing:** 228 crates, all permissive, no
  GPL/AGPL/SSPL. The only crate under a copyleft-ish license with no alternative
  was `option-ext` (MPL-2.0), reached through `directories` — which turned out
  to be **declared but never used**, as did `unicode-segmentation`. Dropping
  both removed 6 crates and left the tree fully permissive.
- `Cargo.lock` is no longer gitignored: this is an application, and Cargo's
  guidance is to commit the lockfile for binaries.
